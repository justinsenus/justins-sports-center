# Justin Senus — Design Consultant

Static portfolio site for GitHub Pages.

The page is built around the approved direction: **Street instinct. Boardroom clarity.** It uses the supplied JS monogram, graffiti mark, Justin portrait, design-process stills, identity board, and process strip directly from the brand kit. The hero uses a transparent cutout of the supplied Justin portrait so the process image and blue JS mark can sit visibly behind him.

## Sections

- Hero / current positioning
- Selected Work
- Past Jobs tab
- Approach
- About
- Contact

The site is dependency-free and can be served from the repository root with GitHub Pages.
