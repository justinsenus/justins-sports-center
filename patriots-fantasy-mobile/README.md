# Patriots + Fantasy Mobile

Compact mobile route for the 2026 Patriots/fantasy dashboard. It uses the same public ESPN/private snapshot feed as the monitor view, plus Sleeper's weekly projection feed when available. It changes `PROJ` player cards and projected team totals to live `PTS`/live totals as games begin; unavailable projections show `—` rather than `0.0`.

Open `/patriots-fantasy-mobile/` after the Pages deployment.
